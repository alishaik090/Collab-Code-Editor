
# 🚀 Collab Code Editor
Real-time collaborative code editor with multi-user editing, chat, and live code execution.

## ✨ Features
- 👥 Real-time collaboration
- 🏠 Room-based coding
- 👑 Host & participant roles
- 💬 Team chat
- ▶️ Run code (Judge0)
- 🌐 Multi-language support
- ⚡ Live cursor sync

## ⚙️ Installation

### Clone
```bash
git clone https://github.com/alishaik090/Collab-Code-Editor.git
cd Collab-Code-Editor
```

### Client
```bash
cd client
npm install
npm start
```

### Server
```bash
cd server
npm install
npm run dev
```

## 🚀 Usage
1. Enter your name  
2. Create room  
3. Share room ID  
4. Start collaborative coding  
5. Run code
